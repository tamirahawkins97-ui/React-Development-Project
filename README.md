# IP Address Tracker

A responsive React and TypeScript web application that allows users to look up geolocation details for any IPv4/IPv6 address or domain and visualizes the location on an interactive Leaflet map.

## ✨ Features
- View visitor's current IP address and location details on initial load
- Search for any valid IP address or domain name
- Real-time map centering with an interactive location marker
- Responsive layout across mobile, tablet, and desktop screens
- Accessible form controls with proper ARIA attributes

## 🛠️ Built With
- **React 18** with **TypeScript**
- **Vite** (Build Tool)
- **IPify Geolocation API** (IP and location lookup)
- **LeafletJS** & **OpenStreetMap** (Interactive mapping)
